# 隐私与安全说明

Browsory 用于在本机整理和检索浏览器历史。应用没有账户系统；浏览记录默认保存在本机，不会自动上传到 Browsory 开发者的服务器。

## 读取与保存的数据

Browsory 可读取所选浏览器配置文件中的访问时间、网页标题、网址和浏览器来源信息，并将其整理到本地归档。读取浏览器数据库时使用临时副本；应用不会主动修改或删除浏览器原始历史库。

你也可以手动导入 Google Takeout JSON、外部 SQLite 历史库或保存离线网页。导入的数据存放在 Browsory 的本地数据目录。

- 安装版使用当前 Windows 用户的数据目录。
- 便携版在程序旁存在 `portable.txt` 时使用同级 `data` 目录。
- 日志和临时文件保存在应用数据目录或系统临时目录。不同版本可能留下旧文件，建议在更换设备或移除应用前检查相关目录。

## 数据库保险库

初始化后的本地历史数据库使用 SQLCipher 页面级加密。保险库由独立口令或恢复密钥解锁；设置的 4 至 6 位 PIN 只锁定应用界面，不代替保险库加密。

从旧版本迁移明文数据库时，应用会保留原数据库备份，以便恢复。确认迁移和备份可用后，可在设置中主动退役该文件。此操作不会处理所有旧备份、浏览器原始数据库或用户导出文件。

加密备份包含恢复所需的数据库和密钥信封。ZIP 容器本身及其文件名、清单等元数据不加密。请将备份保存在可信位置，并单独保管保险库口令或恢复密钥。

保险库解锁时，应用进程会处理解密后的数据。它不能防止已控制当前 Windows 会话的恶意软件读取运行中的进程或原始浏览器数据库。SSD 上删除文件也不保证物理介质上的数据已不可恢复。

## 网络连接

本地搜索、同步浏览器数据库和统计分析在设备上运行。以下操作可能与外部服务通信：

- **AI 和向量服务**：只有在设置并使用对应功能时，应用才会向选定的本地或远程服务发送请求。远程服务会收到请求所需的历史内容；隐私规则可从 AI 请求中排除或脱敏部分记录。请查看服务提供方的隐私政策。
- **WebDAV**：当前版本可以保存服务器设置并测试连通性，双向同步尚未开放。测试连接会联系你配置的服务器，但不会上传浏览记录。
- **链接检查和版本检查**：使用相关功能时会请求目标网站或 GitHub Releases 元数据，不会因此上传完整的浏览历史。

## 导出与删除

CSV、JSON 和 Excel 导出文件是普通文件，不由保险库加密。分享或备份前请检查内容并选择安全位置。

在应用中删除历史记录会更新本地归档和后续同步的排除状态。它不会删除浏览器自己的历史记录、此前导出的副本或已上传到第三方服务的数据。应用主动删除文件时也不承诺 SSD 物理擦除。

## 许可证与问题反馈

Browsory 使用 Apache License 2.0。若发现隐私或安全问题，请通过 GitHub 仓库提交问题；提交前不要附带真实浏览历史、口令、恢复密钥或私密日志。
