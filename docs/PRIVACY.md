# Browsory 隐私说明

Browsory 是本地优先的浏览器历史归档工具。默认不向开发者服务器上传浏览记录。

## 数据存放位置

- 安装版：Windows 本地目录 `%LOCALAPPDATA%\com\browsory\app\`
- 便携版：若程序目录存在 `portable.txt`，数据写在程序旁的 `data\` 目录
- 主数据库：`archive.db`（普通 SQLite，**未加密**）
- 备份：`backups\`
- 日志：`logs\`
- 临时快照：`temp\`

卸载安装包通常不会删除上述目录。请在设置页「存储与诊断路径」中查看并自行决定是否删除。

## PIN 应用锁

PIN 只锁定应用程序界面，防止旁人看到窗口内容。它**不会**加密 `archive.db`。能访问该目录的人可以直接用 SQLite 工具阅读历史。

忘记 PIN 时，用启用时展示的恢复密钥重置应用锁。恢复密钥不能「解密数据库」，因为数据库本来就没有加密。

## 默认不出网

扫描浏览器、导入历史、全文搜索、统计分析都在本机完成。

以下功能**仅在你主动配置后**才会访问网络：

- AI 问答 / 向量嵌入：发往你填写的接口（本地 Ollama 或云端 OpenAI 兼容服务）
- 链接健康检查：向对应网页发 HTTP 请求（已排除内网/保留地址）
- WebDAV：仅允许 HTTPS（本机回环地址可用 HTTP）；当前版本只提供连接测试，双向同步未开放
- 检查更新：请求 GitHub Releases 接口，不携带浏览历史

使用云端 AI 时，相关标题和 URL 会发送到该服务商。云端请求会尽量脱敏 Token、邮箱、身份证号和手机号；命中隐私规则的记录会被排除。

## 卸载

删除程序不会自动清除历史库。如需彻底删除个人数据，请删除上面的数据目录。
