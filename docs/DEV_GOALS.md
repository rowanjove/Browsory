# Browsory 开发目标（来自质量体检）

来源：代码质量 / 产品完整性 / 商业化就绪度审查。只做有真实风险或断裂链路的项。

当前版本：0.1.2  
阶段：Beta

## 立即处理（P1）

1. 启用 PIN 后不要立刻锁屏，必须先展示并可复制恢复密钥。
2. 文案不得暗示 PIN 会加密数据库。PIN 只锁定界面，历史库仍是明文 SQLite。
3. 浏览器运行中的手动同步走只读快照，默认不 `taskkill` 浏览器。
4. License：后端按功能拒绝未授权调用；界面诚实说明免费/Pro 差异。离线授权不假装联网设备计数。
5. 关于页 / 侧栏显示真实版本，并提供检查更新（对照 GitHub Releases）。

## 商业化前处理（P1/P2）

6. 关闭窗口询问「退出 / 最小化到托盘」，可记住选择。
7. 便携版：exe 旁存在 `portable.txt` 时，数据写到 exe 旁 `data/`。
8. 设置页展示数据目录（已有路径卡片，补充便携标记与卸载说明）。
9. 面向用户的隐私说明 + 第三方许可清单。
10. README / 安装包文件名与 0.1.1 产物对齐。
11. 导出和向量检索限制全量加载。
12. 回归测试：PIN 刷新不强制上锁、运行中同步不杀进程、授权拒绝、归档 UPSERT 返回正确 id。

## 发布后按反馈处理

- 导出真正流式写入。
- 单连接 Mutex 拆分。
- WebDAV 双向同步（当前 fail-closed 保持）。
- 数据库损坏启动修复向导。
- SQLCipher 静止加密（不要接现有 `encrypt_migration`）。
